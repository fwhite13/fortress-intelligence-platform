# WI#978 — Tasks: Allow Creating Unlinked (General) Tasks

## Type
Feature

## Source
Lauren Williams feedback (email 2026-03-20 5:52 PM)

## Description
Currently tasks can only be created in the context of a specific account/opportunity. Lauren wants the ability to create general tasks not associated with any account.

## Expected Behavior
- In the Task Center (and/or task creation dialog), provide an option to create a task that is NOT linked to a specific account
- These "general" tasks appear in Task Center alongside account-linked tasks
- "Account" field becomes optional (not required)
- General tasks should be visually distinguishable from account-linked tasks (e.g., no account badge, or a "General" label)

## Current Behavior
Task creation is only available from within an account/opportunity context; all tasks require an account association.

## Notes
- Lauren: "I'd love to create a task not associated with a specific account. This can be more general"
- Consider: Task Center filter to toggle between All / Account-linked / General tasks

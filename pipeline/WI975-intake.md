# WI#975 — All Accounts: Add Search/Filter Bar + Column Sort

## Type
Feature / UX improvement

## Source
Lauren Williams feedback (email 2026-03-20 5:52 PM)

## Description
The All Accounts page currently has no search or filter controls. Lauren requests a search/filter bar at the top (similar to the Pipeline filter bar), plus the ability to sort by clicking column headers.

## Expected Behavior
- Filter bar at top of All Accounts page with:
  - Text search input (search by name, city, etc.)
  - Dropdown filters: Account Status, Opp. Status, Coverage Line, Type, State, Exp. Window
  - Apply and Clear buttons
- Clicking a column header sorts the table by that column (toggle asc/desc)

## Current Behavior
No search or filter controls on All Accounts page. No column sorting.

## Notes
- Lauren included a screenshot of the mock-up showing the desired filter panel layout
- Filter panel style: light gray background, rounded corners, uppercase bold labels, chevron dropdowns
- Consistent with the Pipeline filter bar already in place

# WI#980 — Pipeline: Prospect Click Opens Side-Card (Not New Page)

## Type
Feature / UX change

## Source
Lauren Williams feedback (email 2026-03-20 5:52 PM)

## Description
When clicking a prospect/opportunity card on the Pipeline kanban board, Lauren wants a quick side-card (drawer/panel) to pop out with key details — not navigate to a new full page.

## Expected Behavior
- Clicking a kanban card on the Pipeline page opens a side drawer/panel on the right side of the screen
- Panel shows key opportunity info: company name, stage, assigned AM, premium, effective date, status badge, recent activity summary
- Panel has a "View Full Details" button/link to navigate to the full opportunity page if needed
- Panel is dismissible (click outside or X button)

## Current Behavior
Clicking a kanban card navigates to a new full opportunity detail page.

## Notes
- Lauren: "I like the idea of a quick side card popping out like on demo vs new page"
- This is the interaction shown in the demo that Lauren liked
- Side drawer pattern is preferred for quick review without losing pipeline context
- Full detail page still accessible via explicit navigation from the side drawer

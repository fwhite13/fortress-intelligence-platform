### [22:52] Maria — Critical architectural note from Reed (SPRINT7-SPEC.md)

- `getIntersectionOrNullObject().isNullObject` MUST be read AFTER ctx.sync() — reading before sync always returns undefined (most common ExcelJS proxy bug).
- Table count guard (`if tables.count === 0 return early`) must also come AFTER the sync that loads tables.count.
- `writeToTable()` uses `getItemOrNullObject()` NOT `getItem()` — getItem() throws uncatchably on missing table.
- Routing regex: use positive cell-address pattern `/^[A-Z$][A-Z$0-9]*\d+$/i` rather than negative not-Table-name — avoids SalesData2023 edge case.
- `writeToTable()` passes `pendingTableData.rows` NOT `[headers, ...rows]` — Table manages its own headers.

2. **web_search: fetch failed confirmed pre-deploy:** The Brave proxy was pointing to `localhost` (incorrect for separate Fargate tasks). ADO#3286 fixes this correctly.

3. **Harness:28 has zero production turns:** Deployment is 12 minutes old. All five ADOs are code-verified but not live-verified. The fixes are straightforward with no complex branching.

4. **No CC spawn in harness:28 yet:** `[CC spawn]` log lines (ADO#3289) will appear on the first task-mode turn. Startup check will appear on first harness cold start.

5. **Brave startup 401 is expected:** On startup, the registry service tries to enumerate Brave MCP tools — gets 401 because the Brave API key must be passed per-request (not on ListTools). This is a known non-blocking startup warning.

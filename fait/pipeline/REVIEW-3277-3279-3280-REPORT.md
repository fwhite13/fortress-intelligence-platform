## ADO#3277 — ChatView.razor: `HandleAgentReady()` resumption brief guard

**Verdict: PASS**

### Guard position
Correct. The `if (_resumptionBriefSent) return;` guard appears at the top of `HandleAgentReady()` immediately after `_ = CheckFailedTasksAsync()` — before any `_wasColdStart = true` assignment. All three paths that set `_wasColdStart = true` (session-match path, else branch, and catch block) are below the guard. Early return prevents any of them from executing when the brief was already sent.

### `_resumptionBriefSent` reset on conversation switch
Confirmed. `OnParametersSetAsync` resets `_resumptionBriefSent = false` at line 603, inside the `if (lastConversationId != ConversationId)` branch. Switching conversations properly re-arms the guard.

### Double-brief code paths
No unguarded paths remain. Defense is layered:
1. `HandleAgentReady()` guard prevents `_wasColdStart` from being re-set to `true` after brief has fired.
2. `OnAfterRenderAsync` independently checks `!_resumptionBriefSent` before firing `SendResumptionBrief()`.

The race scenario (two `HandleAgentReady` calls where the second arrives after `OnAfterRenderAsync` has already cleared `_wasColdStart` but before session storage write-back) is now correctly blocked by layer 1.

## ADO#3280 — harness-server.js: error handler HTML sanitization

**Verdict: PASS** (one nitpick — non-blocking)

### `create_document` error handler (line 915–921)
Detection: `errText.trim().startsWith('<') || errText.includes('<!DOCTYPE')`. Both checks correct. After `trim()`, `startsWith('<')` catches `<html>`, `<HTML>`, `<!DOCTYPE html>`, Cloudflare challenge pages, and ALB 502/503 HTML. The `includes('<!DOCTYPE')` is redundant (DOCTYPE starts with `<` and is already caught by the first check) but harmless defensive layering.

Clean message: `Document generation failed (HTTP ${genRes.status}). The API returned an unexpected response.` — status code present. ✓

Non-HTML path: `errText.substring(0, 200)` — truncated, original error surfaced. ✓

### `read_memory` error handler (line 845–849)
Detection: `text.trim().startsWith('<') || text.includes('<!DOCTYPE')` — same pattern. ✓

Clean message: `[non-JSON response, HTTP ${resp.status}]` — status code present. ✓

Non-HTML path: `text.substring(0, 200)` — truncated. ✓

### ⚠️ NITPICK — `write_memory` error handler (line 881–884) — NOT BLOCKING

`write_memory` error path was NOT updated:

if (!resp.ok) {

### 2. Fix plugin/connector terminology in code comments and config (§15.4.1)
Terminology rule from spec:
- **Plugin agents** = domain-specialist AI personas (Marketing, Underwriter, Financial Analyst, etc.) → `agent_plugins` table
- **MCP connectors** = tool integrations / data pipes (MS365, ADO, Web Search, FORGE KB) → `mcp_servers` table

Scan and fix any code comments, XML doc comments, README sections, or inline descriptions that incorrectly label MS365, ADO, Stitch, or FORGE KB as "plugin agents." They are connectors. Update them to say "MCP connector" or "tool group."

Also: if `AgentPlugin.cs`, `IPluginAgentService.cs`, or any agent plugin description strings contain references to "MS365 plugin" or "ADO plugin agent," correct them.

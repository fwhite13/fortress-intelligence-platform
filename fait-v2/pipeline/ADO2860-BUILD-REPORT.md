## Known edge cases / things Clint should scrutinize
- `ContextEnvelopeService.GetSystemClaudeMd()` reads files from disk at runtime — if `wwwroot/claude/` is not included in the publish output, this will fail silently. Ensure `wwwroot/` is published (it is by default for Blazor Server, but worth verifying in the Dockerfile).
- `MemorySummary` is intentionally null for Sprint 4 MVP — the field exists on `CCContextEnvelope` but is not populated yet.
- `BuildEnvelopeAsync` reads KB IDs and connector names from `UserConnector` table via injected services — behavior depends on what `IForgeKbService` and `IConnectorService` return for a given userId. No unit tests exist for this yet.
